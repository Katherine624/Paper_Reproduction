## 训练检查

基础模型：openvla/openvla-7b。公开数据：modified_libero_rlds 中的 libero_spatial_no_noops。使用官方模型、RLDSDataset、RLDSBatchTransform、ActionTokenizer、collator 和交叉熵损失；短训入口为 scripts/train_smoke.py。

LoRA rank=32、alpha=16、dropout=0、all-linear；batch=2，AdamW，lr=5e-4，100 次 optimizer 更新，无梯度累积，开启官方图像增强。可训练参数 110,828,288。

- 首步 loss=11.3460，第 100 步 loss=1.8364；前/后 10 步均值 7.3248/2.8318。来自随机增强训练批次，不是测试集指标。
- 每步 loss、梯度均有限且梯度非零；被检查的 LoRA 参数最大变化 0.0128174。
- 训练步耗时中位数 0.268 秒；峰值 PyTorch allocated 显存 19.65 GiB。
- checkpoint 重载后完成 5 次更新，参数继续变化，动作生成通过；其验证 loss=0.6707。该 loss 使用本轮首个训练批次，仅检查数值有效。
- 恢复了 optimizer/global_step 和 Python、NumPy、PyTorch RNG。RLDS 数据迭代器重新开始，**不声称精确延续样本顺序**。
- 100 步只验证训练管线，不证明收敛；正式成功率来自官方 Spatial 权重，不是这个短训 adapter。
