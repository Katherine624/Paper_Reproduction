## 训练 checkpoint

| 目录 | 含义 |
|---|---|
| results/train-smoke/checkpoint-50 | 第 50 步快照 |
| results/train-smoke/checkpoint-100 | 最初 100 步训练的结束状态 |
| results/train-smoke/checkpoint-105 | 从第 100 步恢复、再训练 5 步后的状态；这是最新 checkpoint |

每个 checkpoint 均包含：

- adapter_model.safetensors：本次训练保存的 LoRA 权重。
- training_state.pt：优化器、global_step、Python/NumPy/PyTorch 随机数状态。
- adapter_config.json、tokenizer 文件、preprocessor_config.json、dataset_statistics.json：加载和动作反归一化所需的配置。

这些是 LoRA checkpoint，加载时仍需原始 OpenVLA-7B 基础模型。基础模型仓库是 [openvla/openvla-7b](https://huggingface.co/openvla/openvla-7b/tree/47a0ec7fc4ec123775a391911046cf33cf9ed83f)，本次固定 revision 为 `47a0ec7fc4ec123775a391911046cf33cf9ed83f`。不要用已经微调好的 Spatial 权重代替这个基础模型。完整下载信息及校验值见 source_manifest.json。

## 继续训练示例

在配置好同版本 OpenVLA 环境的 Linux/CUDA 机器上，先设置实际路径：

```bash
BACKUP=/your/path/openvla_full_backup
CODE=/your/path/openvla-source
BASE=/your/path/openvla-7b
DATA=/your/path/rlds-data
OUT=/your/path/new-training-run
export PYTHONPATH="$CODE:$BACKUP/scripts:$PYTHONPATH"

python "$BACKUP/scripts/train_smoke.py" \
  --model "$BASE" --data "$DATA" --out "$OUT" \
  --resume "$BACKUP/results/train-smoke/checkpoint-105" \
  --steps 110 --batch-size 2
```

--steps 110 表示继续到全局第 110 步，即从第 105 步再训练 5 步。配置中的旧服务器绝对路径原样保留，迁移后通过 --model、--data、--resume、--out 显式指定新路径。恢复优化器与随机数状态时，RLDS 迭代器仍会重新开始，不保证精确延续原样本顺序。

100 步训练只用于检查流程；84% 的正式评测结果来自官方 Spatial checkpoint，与这些短训 LoRA checkpoint 分开记录。
